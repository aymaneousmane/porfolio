# Portfolio — Projets universitaires

Ce dépôt rassemble une sélection de travaux universitaires réalisés en mathématiques appliquées, statistiques, analyse numérique, informatique scientifique et génie logiciel.

Les projets prennent la forme de rapports, présentations, notebooks Jupyter, scripts MATLAB/R et jeux de données associés.

## Projets

### Analyse et bases de données

Le dossier [`ABD/`](ABD/) contient une présentation et un cas pratique d'analyse de données commerciales :

- rapport et supports de présentation sur l'analyse et les bases de données ;
- notebook [`code_pratique.ipynb`](ABD/cas%20pratique/code_pratique.ipynb) ;
- jeu de données [`sales_sale.csv`](ABD/cas%20pratique/sales_sale.csv).

### Analyse numérique 3

Le dossier [`AN3/`](AN3/) regroupe un projet d'analyse numérique avec son notebook, son rapport et sa présentation finale.

### Optimisation, calcul scientifique et systèmes d'équations

Le dossier [`OCS/`](OCS/) présente plusieurs travaux numériques réalisés avec Python et MKL : résolution de systèmes d'équations, résolution d'équations et modélisation SIR.

### Équation de Schrödinger

Le dossier [`Probleme_instationnaire/`](Probleme_instationnaire/) contient l'étude numérique d'un problème instationnaire lié à l'équation de Schrödinger, avec rapports, présentations et script MATLAB.

### Chaînes de Markov

Le dossier [`chaine de markov/`](chaine%20de%20markov/) contient un travail consacré aux chaînes de Markov, accompagné de rapports et de présentations au format PDF.

### Projets déterministes

Le dossier [`projet_deterministe/`](projet_deterministe/) rassemble des notebooks consacrés aux méthodes d'Euler explicite et implicite, à l'analyse d'erreur et à la méthode de Runge-Kutta d'ordre 4.

### Séries temporelles

Le dossier [`serie temp/`](serie%20temp/) contient une étude de la relation de long terme entre les prix de l'or et de l'argent à l'aide d'un modèle à correction d'erreur et de la procédure d'Engle-Granger.

### Génie logiciel

Le dossier [`genie logiciel/`](genie%20logiciel/) contient le rapport du projet de génie logiciel.

## Outils utilisés

Selon les projets, les travaux utilisent notamment : **Python**, Jupyter Notebook, **R**, R Markdown, **MATLAB**, Intel MKL, **LaTeX** et Beamer.

## Utilisation

Les fichiers PDF peuvent être consultés directement depuis GitHub. Pour exécuter les notebooks ou scripts, installez l'environnement correspondant au projet :

```bash
git clone https://github.com/aymaneousmane/porfolio.git
cd porfolio
```

Les dépendances peuvent varier d'un dossier à l'autre. Les notebooks et rapports constituent la documentation de référence de chaque projet.
